# Roadmap de 90 Dias – Mês 3  
## Portfólio, Consolidação e Preparação para Entrevistas

O terceiro mês é dedicado a consolidar tudo o que foi aprendido, finalizar o projeto de portfólio e preparar-se para processos seletivos.  
É o momento de transformar conhecimento e prática em **material profissional apresentável**.

---

# Semana 9 – Estruturação do Projeto de Portfólio

### Objetivos:
- Organizar todo o conteúdo criado nos meses anteriores.
- Estruturar o projeto principal de treinamento.

### Atividades:
- Reunir:
  - Módulos de treinamento  
  - Checklists  
  - Apostilas  
  - Roteiros  
  - Simulações  
- Criar a estrutura final do projeto na pasta **04-projeto-portfolio**.
- Definir o formato final do programa de treinamento.

---

# Semana 10 – Finalização dos Materiais

### Objetivos:
- Refinar e padronizar todos os materiais.
- Garantir clareza, profissionalismo e aplicabilidade.

### Atividades:
- Revisar:
  - Linguagem  
  - Layout  
  - Exemplos  
  - Fluxos  
- Criar versões finais dos módulos.
- Criar um documento de apresentação do programa de treinamento.

---

# Semana 11 – Preparação para Entrevistas

### Objetivos:
- Preparar respostas profissionais baseadas em experiências reais.
- Treinar comunicação e postura.

### Atividades:
- Preencher a pasta **05-roteiro-entrevistas** com:
  - Perguntas comuns  
  - Respostas estruturadas  
  - Exemplos reais do varejo  
- Criar respostas usando a técnica STAR (Situação, Tarefa, Ação, Resultado).
- Treinar apresentações curtas (pitch profissional).

---

# Semana 12 – Consolidação e Posicionamento Profissional

### Objetivos:
- Finalizar o portfólio.
- Preparar-se para apresentar o projeto em entrevistas.
- Organizar presença profissional.

### Atividades:
- Revisar todo o repositório.
- Criar um resumo profissional para LinkedIn.
- Preparar uma apresentação curta do projeto de treinamento.
- Criar um documento final com:
  - Objetivo do programa  
  - Estrutura  
  - Módulos  
  - Benefícios para a empresa  

---

# Resultado Esperado ao Final do Mês 3

- Projeto de portfólio completo e profissional.  
- Materiais revisados e padronizados.  
- Roteiro de entrevistas pronto.  
- Apresentação profissional estruturada.  
- Preparação sólida para processos seletivos.
